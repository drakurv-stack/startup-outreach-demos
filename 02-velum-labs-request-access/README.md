# Demo 02 — Velum Labs request-access redesign (concept)
**Target:** Velum Labs — https://velum-labs.com/ (YC Winter 2026, 2 employees; now pitching "RouteKit")
## The issue (verified on the live site, 2026-10-11)
The entire site has **zero conversion CTAs**. The only links anywhere are a skip link, the logo, `mailto:founders@velum-labs.com`, and their X profile — the single `<button>` on the page is a dark-mode toggle. No signup, waitlist, demo, or contact form exists, so interested visitors have nowhere to go.
## The fix (this demo)
A mobile-first hero + request-access section matching their RouteKit positioning: sticky nav with a persistent "Request access" button; headline + one-line RouteKit value prop + email capture form; three supporting points; inline validation with accessible error/success states; fully responsive (stacked form on mobile, inline on desktop); `index.html` is a single self-contained file — no build step, no dependencies.
## View it
Open `index.html` in any browser, or see it live via GitHub Pages (link in repo About).
