# Startup Outreach Demos
Small, focused frontend demo fixes built for real early-stage startups — each one pairs with a cold email showing the fix instead of just describing it.
## Demos
| # | Startup | Issue fixed | Demo |
|---|---------|-------------|------|
| 01 | [Polymorph](https://usepolymorph.com/) (YC W26) | Landing page had zero CTAs — only a mailto link | [01-polymorph-waitlist-redesign](./01-polymorph-waitlist-redesign/) |
## How each demo is built
1. Pick an early-stage startup with a publicly visible website issue (verified on the live site, never invented).
2. Build a minimal, mobile-friendly demo of the fix as a single self-contained HTML file.
3. Document the observed issue and the fix in the demo's README.
4. Send the cold email with the live demo link.
