# Demo 01 — Polymorph waitlist redesign (concept)
**Target:** Polymorph — https://usepolymorph.com/ (YC Winter 2026, secure infrastructure)
## The issue (verified on the live site, 2026-10-11)
The Polymorph landing page has **zero call-to-action buttons**. The entire page is a short paragraph plus a bare `mailto:founders@usepolymorph.com` text link — there is no way for a visitor to sign up, join a waitlist, or request a demo. Every interested visitor has to manually compose an email, which kills conversion.
## The fix (this demo)
A mobile-first hero + waitlist capture section in the same minimal spirit as their brand: sticky nav with a persistent "Join waitlist" button; clear headline + one-line value prop + email capture form; inline validation with accessible error/success states; fully responsive (stacked form on mobile, inline on desktop); `index.html` is a single self-contained file — no build step, no dependencies.
## View it
Open `index.html` in any browser, or see it live via GitHub Pages (link in repo About).
